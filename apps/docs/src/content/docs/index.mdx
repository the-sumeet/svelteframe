Svelteframe lets you make videos out of Svelte 5 components. You describe what the screen looks like **at frame `n`**, and the tools turn that description into an MP4:

1. A headless Chromium opens your composition and steps through its frames.
2. Each frame is captured as an image.
3. `ffmpeg` encodes the images (and any audio) into a video.

Because every frame is computed from its number alone, the same composition always renders the same video, on any machine, in any order, in parallel.

```svelte
<script lang="ts">
  import { AbsoluteFill, interpolate, useVideo } from '@svelteframe/core';

  const video = useVideo();
  // 0 at frame 0, 1 at frame 30, and it stays there.
  const opacity = $derived(interpolate(video.frame, [0, 30], [0, 1]));
</script>

<AbsoluteFill style="background:#0f1722;color:white;align-items:center;justify-content:center">
  <h1 style="opacity:{opacity}">Hello, video</h1>
</AbsoluteFill>
```

## What is in the box

| Package | What it is for |
| --- | --- |
| `@svelteframe/core` | Svelte components and helpers: `Sequence`, `Series`, `interpolate`, `spring`, `Audio`, `OffthreadVideo`, `Player`, ... |
| `@svelteframe/shapes` | SVG shapes (`Rect`, `Circle`, `Arrow`, ...) on a canvas the size of the video, with arrows that attach to shapes by id. |
| `@svelteframe/renderer` | The Node API behind rendering: `renderVideo` and `renderStill`. |
| `@svelteframe/cli` | The `svelteframe` command: `render`, `still` and `compositions`. |
