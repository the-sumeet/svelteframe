Svelteframe lets you make videos programmatically using Svelte 5 components. A video is a deterministic function of the current frame number: a headless browser steps frame-by-frame, captures each frame, and `ffmpeg` encodes them into an MP4 video.

## Prerequisites (System-wide)

Before you begin, ensure you have:
- **Node.js 22+** (Node 24 recommended)
- **ffmpeg** installed on your system:
  - macOS: `brew install ffmpeg`
  - Linux (Ubuntu/Debian): `sudo apt install ffmpeg`
  - Windows: `winget install Gyan.FFmpeg`

## Getting Started

<Tabs>
  <TabItem label="Option 1: Quick Start in this Repo (Recommended)">

If you have cloned the Svelteframe repository, everything is already wired up in `apps/playground`. You do **not** need to create any new directory!

<Steps>

1. **Install dependencies and build the workspace:**
   ```sh
   pnpm install
   pnpm build
   ```

2. **Install Chromium for Playwright (one-time setup for rendering):**
   ```sh
   pnpm --filter @svelteframe/renderer exec playwright install chromium
   ```

3. **Launch the interactive Player in your browser:**
   ```sh
   pnpm dev:play
   ```
   Open the printed URL (usually `http://localhost:5173`). You will see all example compositions with a timeline scrubber to preview them in real time.

4. **Render an MP4 video from the terminal:**
   ```sh
   pnpm svelteframe render main
   ```
   This will render the `main` composition into `main.mp4` in your root folder.

</Steps>

  </TabItem>
  <TabItem label="Option 2: In a New Standalone Project">

To use Svelteframe in your own standalone project, create a new SvelteKit app:

<Steps>

1. **Create your project folder:**
   ```sh
   npx sv create my-video-app
   cd my-video-app
   ```

2. **Install Svelteframe packages:**
   ```sh
   npm install @svelteframe/core @svelteframe/shapes
   npm install -D @svelteframe/cli @svelteframe/renderer
   npx playwright install chromium
   ```

3. **Create your first video component:**
   See [Your first composition](/getting-started/first-composition/) to write your component, and [Setting up a project](/getting-started/project-setup/) to wire the render route.

4. **Render with the CLI:**
   ```sh
   npx svelteframe render <composition-id>
   ```

</Steps>

  </TabItem>
</Tabs>
